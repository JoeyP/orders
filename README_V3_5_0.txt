B&L Neeley Orders V3.5.0 — Blend Alignment Rebuild

Includes everything through V3.4.9.

CHANGE
The Admin Blend column was rebuilt so it no longer relies on the previous
spacer/offset approach. It now renders one structural Blend row for every
order item, with a matching header row, so checkbox #1 belongs to item #1,
checkbox #2 to item #2, etc.

All V3.4.9 features remain:
- 2x2 New Order success buttons
- Admin Ready green
- overdue/today red
- tomorrow orange
- Back Ordered charcoal
- Blending Complete workflow
- simplified Tracker

No SQL required.
Replace all website files from this package except config.js.
